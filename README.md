# LogiTrack — Project Overview

**Project type:** Full Stack Web Application  
**Domain:** Transportation & Logistics  
**Status:** Planning

## 1. Project Description

LogiTrack is a shipment management and tracking web application designed to centralize shipment information and provide visibility into delivery progress.

The project aims to explore how software solutions can support logistics operations, improve information management and simplify shipment tracking.

## 2. Problem Statement

Shipment management involves different stages, status updates and operational events.

When information is scattered or difficult to access, tracking deliveries and identifying potential delays can become challenging.

LogiTrack aims to address this problem by providing a centralized platform where users can manage shipments and consult their tracking history.

## 3. Project Objectives

- Centralize shipment information.
- Provide visibility into shipment status.
- Maintain a history of shipment events.
- Identify delayed or problematic shipments.
- Present relevant operational information through a dashboard.

## 4. Target Users

**Operations Staff**

Responsible for registering shipments, updating statuses and monitoring delivery progress.

**Administrators**

Responsible for managing system information and monitoring overall operations.

**Customers**

Potential future users who can consult shipment information and delivery progress.

## 5. Proposed Core Features

- Shipment registration and management.
- Customer information management.
- Shipment status updates.
- Tracking history.
- Search and filtering.
- Dashboard with operational indicators.

## 6. Initial Project Scope

The first version (MVP) will focus on shipment management, tracking history and operational visibility.

Advanced features such as external carrier integrations, automated notifications and real-time GPS tracking are outside the initial scope.

## 7. Expected Outcome

A functional web application demonstrating how software development, database management and logistics processes can be combined to create a practical digital solution.

## 8. Proposed Technologies

- Backend: C# / ASP.NET Core Web API
- Frontend: React / TypeScript
- Database: SQL Server
- API documentation: Swagger / OpenAPI
- Version control: Git / GitHub
